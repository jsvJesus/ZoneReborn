Инструкция по заполнению stalker-online\res\scripts\common\data\PremiumAccountConfig.json


Структура файла PremiumAccountConfig.json:

{
	"configs": [
		{
			"price": 300,
			"ExpCoefficient": 2.0,
			"days": 30,
			"name": "PremiumAccountConfigs.STANDART",
			"description": "PremiumAccountConfigs.descriptions.premium_id_0",
			"premium_id": 0
		},
		
		...
		(следующие уникальные конфиги, по структуре анологичные выше-приведенному)
	]
}

где:

price - цена премиума,
ExpCoefficient - множитель опыта,
days - длительность премиума в днях,
name - локализованное название премиума (файл локализации PremiumAccountConfigs),
description - локализованное описание премиума,
premium_id - уникальный ID конфигурации


1. ID премиумов должны быть уникальными.

2. Конфигурационный файл читается как на сервере так и на клиенте
		1. но на клиенте видны только открытые (не скрытые конфиги)

3. Скрытые конфиги не видны пользователям и их нельзя активировать.
		1. Скрыть или открыть конфиг можно через веб-консоль 
			(команда "Premium Accoun Show Hide Configs").
		2. Скрытие\Открытие конфига для пользователя вступает в действие 
			во время входа или выхода из окна аккаунта.

4. Пользователь, купивший премиум, до его скрытия видит его у себя в меню 
		и продолжает им пользоваться пока не истечет срок премиум аккаунта.

5. Новый конфиг вступит в силу только после 
	1. push'а на сервер
	2. перезапуска сервера
	3. обновления клиента

6. Все нововведенные конфиги нужно после пуша и перезапуска сервер делать видимыми через веб-консоль
		1. Делается это в веб-консоле с помощью команды Premium Accoun Show Hide Configs

7. Посмотреть какие существуют конфиги и какие из них скрыты, 
		а какие видимы можно в веб-консоле с помощью команды "Premium Account Config Table"
