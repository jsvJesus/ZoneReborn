Разработка проекта ZoneReborn:
Название проекта: ZoneReborn.
Модули внутри проекта:
	1) Engine - движок, воспомогательные системы, функции, для написания кода. Применяется к Game, Editor, Server.
	2) Game - сам игровой клиент.
	3) Editor - игровой редактор.
	4) Server - игровой сервер.
	
Правила написании кода и архитектуры проекта:
1. Правила:
	1) Мы делаем игру на базе игровых ассетов игры Stalker Online.
	2) Мы работаем в программе Rider и пишем код, основа игры С++.
	3) Название проекта ZoneReborn.
	4) Название в файлах и в функциях не используем.
	5) Пишешь код без примеров и прочего. Код писать в чат с инструкцией.
	6) Используешь Код игры в "packs/" как референс.
	7) Мы не должны использовать Bigworld как пример.
	8) Не ебашть код в одном файле, правильно структурировать всё.
	9) Не разделяем файлы по папкам (public/private)
2) Архитектура проекта:
	ZoneReborn/
	│
	├── src/							- .sln файл внутри папки src
	│   ├── Engine/						- Движок игры
	│	│	├── Core/	
	│	│	├── Renderer/	
	│	│	├── Scene/	
	│	│	├── Assets/	
	│	│	├── Animation/	
	│	│	├── Physics/
	│	│   └── UI/
	│	│	│	├── Editor/				- Используем DearImgui
	│	│	│	├── Game/				- Используем .php/.js/.css/.html
	│   ├── WorldEditor/				- Генератор мира, Terrain, Объекты, дороги, биомы.
	│	│	├── Terrain/				- Высоты, горы, долины, овраги и эрозия.
	│	│	├── Biome/					- Леса, болота, поляны и растительность, вода и реки.
	│	│	├── Settlement/				- Деревни, посёлки, города и промышленные зоны.
	│	│	└── Road/					- Дороги, развилки, мосты и тропинки.
	│   ├── Editor/						- Редактор
	│	│	├── Viewport/	
	│	│	├── TerrainEditor/	
	│	│	├── WorldGenerator/
	│	│	├── AssetBrowser/	
	│	│	├── MaterialEditor/
	│	│	└── SceneEditor/
	│   ├── Builder/					- Компиляция игровых ресурсов
	│   ├── Updater/					- Лаунчер
	│   ├── Extertals/					- SDK (тут будут лежать дополнения) типа PhysX, DearImgui и тд.
	│   └── Game/						- Клиент
	├── Server/
	└── bin/							- .exe файлы внутри папки bin
		└── packs/						- игровые ресурсы
