# Игровые файлы папки packs:

## Структура

Папка `audio/` содержит звуковые файлы.
Папка `characters/` персонажи v1 (старые)
Папка `characters2/` персонажи v2 (будем использовать этих)
Папка `environments/` игровое окружение
Папка `extendedGUI/` распакованные ресурсы UI
Папка `headpresets/` конфиги
Папка `helpers/` конфиги
Папка `local/` языки
Папка `materials/` материалы
Папка `models/` игровые модели
Папка `particles/` партиклы
Папка `scaleformUI/` распакованные доп. ресурсы UI
Папка `scripts/` распакованные пайтон скрипты + конфигы игры
Папка `sfx/` конфиги
Папка `soGUI/` картинки и ресурсы UI
Папка `speedtree/` ресурсы
Папка `system/` системные конфиги
Папка `textures/` текстуры
Папка `weather/` конфиги погоды
